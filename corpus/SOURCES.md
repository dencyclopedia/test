# Corpus sources and licences

Every image in this corpus is **generated** by the scripts in `corpus/gen/` (rendered text, or a real
Chromium screenshot of a local HTML page written for this corpus). No third-party image is included.
All images carry `"synthetic": true` in `manifest.json`.

## Texts

| Used for | Source | Licence |
|---|---|---|
| `clean`, `degraded`, `layout` sets (`corpus/texts/{austen,doyle,shelley,carroll}.*.txt`) | Project Gutenberg eBooks #1342 *Pride and Prejudice* (Jane Austen), #1661 *The Adventures of Sherlock Holmes* (Arthur Conan Doyle), #84 *Frankenstein* (Mary Shelley), #11 *Alice's Adventures in Wonderland* (Lewis Carroll), fetched from the `gutenberg.pglaf.org` mirror | Public domain (the works; authors died before 1931). Only the work's text is used; no Project Gutenberg trademark/licence text is reproduced. |
| `multilingual` set (`corpus/texts/udhr_*.txt`) | Universal Declaration of Human Rights translations from the Unicode "UDHR in XML" project, as packaged in the NLTK data corpus `udhr2` (`https://raw.githubusercontent.com/nltk/nltk_data/gh-pages/packages/corpora/udhr2.zip`) | Listed as `license="public domain"` in NLTK's `index.xml`. The UDHR is a UN General Assembly resolution (A/RES/217(III)); OHCHR publishes the translations for free reproduction. |
| `receipt` set | Item names, prices, dates and store names generated by `build_corpus.py` with a fixed seed. Store names and addresses are invented and every receipt says "Sample receipt - not a real store". | Written for this corpus (CC0) |
| `line`, `word`, `sparse`, `screenshot` sets | Short strings and HTML written for this corpus | Written for this corpus (CC0) |

Download hashes (sha256) of the Gutenberg files and of `udhr2.zip` are in `corpus/texts/sources.json`.

Text edits made by `fetch_sources.py` before rendering (the ground truth is the edited text):
- Gutenberg `_italic_` underscores removed; `[Illustration: ...]` captions removed; line wraps joined.
- U+2010 HYPHEN (used in the UDHR files) replaced by ASCII `-`.
- Whole sentences are taken until a character budget is reached (`*.page.txt` ~1,100 chars,
  `*.half.txt` ~520 chars, UDHR pages ~650 chars or ~280 for Chinese/Japanese/Korean).
- Portuguese uses the European Portuguese file (`por_PT`), Uzbek the Latin-script file (`uzn_latn`),
  Chinese the Simplified file (`cmn_hans`), Arabic the Standard Arabic file (`arb`).

## Fonts

System fonts (Ubuntu 24.04 packages): DejaVu Serif/Sans/Sans Mono (Bitstream Vera licence / public domain changes),
Caladea and Carlito (OFL 1.1), Inter (OFL 1.1), JetBrains Mono (OFL 1.1), FreeSerif/FreeSans/FreeMono (GPL with font
exception), Bitstream Charter and Courier 10 Pitch (Bitstream donated licence, X11 Type1), IPAGothic (IPA Font Licence).

Downloaded by `fetch_sources.py` from `github.com/google/fonts` at commit
`7af0d90b4d532ffa4b041937b560c6df4e7b1e95` (all SIL Open Font License 1.1), sha256-checked, not committed:
Noto Sans SC, Noto Sans KR, Noto Naskh Arabic, Noto Sans Devanagari (variable fonts, "Regular" instance).

Fonts are only used to draw the images; no font file is redistributed in this repo.
